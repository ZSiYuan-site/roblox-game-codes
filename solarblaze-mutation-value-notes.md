# Solarblaze Mutation Fisch: Value Notes and Best Fish

Solarblaze is a standard ×3 mutation in Fisch. Here is what it is worth and how to use it.

## The basics

Solarblaze is a ×3 standard mutation and it is not appraisable. That matters because appraisable mutations can be re-rolled, while this one is fixed once applied.

## Best fish to use it on

The Magician Narwhal is the standout: with Solarblaze it sells for 1,905,000 C$ at average weight. The [Solarblaze mutation Fisch](https://newgamescout.com/fisch/mutations/solarblaze) page has a top-10 fish table with the exact sale value for each species.

## How to read the numbers

Values move with weight and game updates. The table uses average weight so you can compare fish on equal terms. If you are choosing between mutations, compare the multiplier and whether the mutation can be appraised.
