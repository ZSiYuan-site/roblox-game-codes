<h2>Redeeming step by step</h2>
<p>The page lists four steps. Finish the prologue and reach the Dijiang, because the Mail feature unlocks a little later in the story. Then press Esc on PC or open the main menu, and go to Settings. Open the Platform and Account tab and select Exchange Code. Enter one code exactly as written and confirm. Each code works once per account.</p>
<p>The most common failure is trying to redeem before you reach that point in the story. If the Exchange Code option does nothing for you, play a little further and try again. The second most common is typing. The FAQ on the page says codes are case-sensitive, so use the Copy button.</p>
